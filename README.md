# ai-last30days

Monthly AI briefings built with [`/last30days`](https://github.com/mvanhorn/last30days-skill), which pulls what people actually said on Reddit, X, Hacker News, GitHub and YouTube over a 30-day window, then lays it out as a readable brief.

**Current issue: [Frontier on Hold](https://johnsonishere.github.io/ai-last30days/)** — 20 September to 20 October 2026. Model updates, AI engineering trends, AI safety, and Europe's AI argument with itself.

Sources this issue: 34 Reddit threads, 6 X posts, 39 Hacker News stories, 13 GitHub items, 3 YouTube videos, 18 news articles. Coverage caveats are listed in the page's colophon.
